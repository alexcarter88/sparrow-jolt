Sparrow on Lightning — a tiny amber sparrow rides a jagged lightning bolt as it dives diagonally through a violet storm, rain streaking past — the smallest bird in the sky surfing the biggest force in it. The jolt is the whole idea: one look lands like a shock, the bolt's diagonal drags the eye from corner to corner, and the bold amber silhouette against electric blue still reads at a glance. The caption says it plainly to the judge: FEEL THE JOLT.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node --experimental-strip-types main.ts
```

It copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`, byte for byte, every run.
